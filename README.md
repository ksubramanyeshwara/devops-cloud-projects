# ♾️ DevOps & ☁️ Cloud Projects

This repository contains a collection of real-world DevOps and Cloud projects where I implemented real-world CI/CD pipelines, containerization, and AWS infrastructure.

Whether you're just starting your DevOps journey or sharpening your expertise, you'll find practical examples here with clear explanations and ready-to-run code.

## 🗂️ What's Inside

Projects are in separate folders. Each folder has its own detailed `README.md` with step-by-step instructions, architecture overview, and usage examples.

- **Monitoring**: Prometheus | Grafana
